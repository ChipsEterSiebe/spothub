Spotify HUD

Verbind je Spotify-account om live te tonen wat je luistert. Er is geen server nodig, je gegevens blijven in deze browser.

  1. Maak een app op developer.spotify.com/dashboard en kies Web API.
  2. Voeg hieronder staande Redirect URI toe aan die app en sla op.
  3. Plak je Client ID en klik op verbinden.
